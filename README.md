# Дадан шежіресі

Интерактивное шежіре потомков Дадана по книге «Даданнан өзіме дейін» (с. 37–57).
Линия Дадан → Алакөз → Жөбалай → Қылыш → Шот → Қожантай → Бұғытай → Шантай → Жаманбала → Бертісбай → Шайық → Фермебай → Есенғалы выделена золотой ветвью.

Сайт — один файл `index.html`, публикуется через GitHub Pages (ветка `main`, корень).
